Default Point of Sale screens in Odoo are rigid and can leave awkward empty voids during checkout. Samay POS UI Designer gives business managers full visual command over checkout geometry, typography, button visibility, and branding colors without writing a single line of XML or QWeb code.

Quick Setup

Easy 4-Step Configuration

1

Install the Module

Deploy `samay_pos_ui_designer` into your Odoo 20 custom addons directory and click Install in the Apps menu.
2

Open Point of Sale > POS UI Designer

Navigate to Point of Sale > Configuration > POS UI Designer and create or edit a layout profile.
3

Customize Layouts & Verify in Preview

Configure sales and payment positions, select a color theme preset, check the live preview tab, and save.
4

Assign to POS & Start Register

Assign the profile to your POS configuration and start a session. The custom theme applies smoothly on load.
