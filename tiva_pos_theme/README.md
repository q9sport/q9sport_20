# TIVA POS Dark Theme (Odoo 20)

A CSS-only visual theme for Odoo 20 Point of Sale, inspired by the provided TIVA POS reference.

## Install
1. Copy `tiva_pos_theme` into your custom addons path.
2. Restart Odoo and update the Apps list.
3. Install **TIVA POS Dark Theme**.
4. Open the POS with a hard refresh (Ctrl+Shift+R).

## Notes
- This addon changes appearance only; it does not change order, payment, barcode, stock, or cashier business logic.
- This is a first-pass theme and must be visually checked on the target Odoo 20 build. Odoo's exact markup/classes can differ by build and other installed POS modules, so layout-specific refinements may be required for an exact match to the reference.
